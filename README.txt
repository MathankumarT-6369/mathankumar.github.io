# Mathankumar Data Analyst Portfolio

Files:
- index.html
- style.css
- script.js
- assets/profile.jpg

Open index.html in a browser to preview the portfolio.

Before publishing:
1. Replace `your-email@example.com` in index.html with your real email.
2. Replace the GitHub placeholder with your GitHub URL.
3. Put your resume PDF inside `assets/resume.pdf` and change the Resume button link to `assets/resume.pdf`.
4. Update project links later when your GitHub repositories are ready.

Free deployment options: GitHub Pages, Netlify, or Vercel.
